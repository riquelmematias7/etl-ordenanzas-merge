# 🏛️ Automatización y Merge de Ordenanzas Fiscales

Script desarrollado en **Python** para procesar, unificar y automatizar el cálculo y la actualización de documentos de tasas municipales.

## 📋 Descripción del Proyecto
Este proyecto resuelve el desafío operativo de mantener actualizados los cuadros tarifarios y normativas fiscales. A través de este script, se automatiza la lectura, el cálculo y el cruce (*merge*) de datos provenientes de distintas normativas municipales, eliminando el trabajo manual repetitivo, reduciendo a cero el margen de error humano y bajando los tiempos de procesamiento de horas a segundos.

## ⚙️ Características Principales
- **Procesamiento de Datos:** Lectura y cruce de múltiples fuentes de datos tarifarios.
- **Cálculo Automatizado:** Aplicación de fórmulas de actualización de tasas según parámetros normativos.
- **Generación de Reportes:** Exportación de documentos consolidados listos para la liquidación fiscal.
- **Escalabilidad:** Diseñado para manejar múltiples tipos de ordenanzas y tasas de manera modular.

## 🛠️ Stack Tecnológico
- **Lenguaje:** Python 3.x
- **Librerías principales:** `pandas` (o las que hayas utilizado para el manejo de datos).
